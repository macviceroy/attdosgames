# Exportações reais do Studio

- `neon/`, `arcade/`, `cinema/`: mesmo material, estilos distintos,6s cada.
- `variation-1.mp4` a `variation-3.mp4`: segmentos distintos,10s cada.
- `intro-hyperframes.mp4`: animação HTML/CSS opcional,3s, sem áudio.
- `editor.png`, `variations.png`: capturas reais do editor no navegador.

Arte e sinais sonoros de teste procedurais originais CC0. Não são cenas de GTA
nem voz humana. Não aprovados editorialmente para publicação. Relatórios têm
IDs locais de assets; projetos de exemplo documentam a timeline, mas requerem
recriar/importar fixtures com `scripts/studio_e2e.py` para editar as entradas.
Nenhum banco, token, cache ou arquivo temporário novo incluído.

`integrated-motion.mp4`: intro HyperFrames + clipe + música procedural,6s, QC aprovado.
